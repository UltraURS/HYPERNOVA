# HYPERNOVA

面向 HyperOS 3 的 LSPosed 模块，提供控制中心截屏菜单、每日流量显示、侧边栏手势和通知管理等功能。

> [!IMPORTANT]
> 本模块为 **Vibe Coding 项目**。若在使用本模块过程中出现任何不可逆的后果，本人概不负责。

当前开发版为 **0.2.25-dev**。项目以 GPLv3（`GPL-3.0-only`）发布。 [下载 APK 和校验文件](https://github.com/UltraURS/HYPERNOVA/releases) · [许可证](LICENSE) · [版权与移植说明](NOTICE)

## 当前开发版

| 功能 | 本版实现范围 |
| --- | --- |
| 今日移动流量 | SystemUI 磁贴标题；后台查询、30 秒刷新、缓存日期/时区校验、监听结束停止 |
| 隐藏系统更新条目 | 仅设置中 key 为 `miui_updater` 的条目；不含搜索、通知、联网或安装阻断 |
| 隐藏恢复出厂入口 | “我的设备”条目、底部推荐及设置搜索中的对应结果；不阻止实际重置 |
| OTA 客户端状态 | 实际查询当前用户的 `com.android.updater`；缺失显示不适用，存在但未核验显示待适配，不误报已阻断 |
| 通知锁定与置顶 | 长按菜单增加锁定/置顶；按单条通知 key 各选一条，置顶条目脱离分组；点击取消立即恢复 |
| 通知中心一键清理 | 底部居中的系统清理按钮；保留锁定及系统不可清除的通知，单独置顶不妨碍清理 |
| 返回手势呼出侧边栏 | 从左右两侧系统返回就绪震动开始计时，到期再次震动并切换图标，松手打开对应侧原生面板，回划取消；阈值 0.10～0.50 秒，默认 0.30 秒 |
| 隐藏系统侧边栏触发条 | 收起状态下原生窗口完全透明且不可触摸，保留面板；展开时恢复原交互，不接管桌面返回手势 |
| 屏蔽日历广告 | 使用原生推广关闭分支，拦截专用广告请求、取消可识别在途请求，抑制缓存广告卡片 |
| 屏蔽天气广告 | 拦截预报与首屏专用广告请求，隐藏详情广告容器，过滤共用内容及缓存里的广告节点，保留普通内容 |
| 侧边栏向外滑动收回 | 在应用列表上左侧向左、右侧向右滑动后松手，调用原生收回动画；区分纵向滚动、长按及多指 |
| 小窗右上角关闭按钮 | 普通小窗右上角显示 ×，随小窗移动、缩放；点击复用原生关闭，将当前小窗任务转到后台 |
| 蓝牙自动重连 | 系统设备详情页逐台开启，1～5 次含首次；请求后等待连接 15 秒，连接出现后稳定确认 5 秒；短暂连接不重置次数，失败或稳定连接后断开间隔 10 秒；手动整机断开后暂停，重新开蓝牙或重启恢复 |
| 蓝牙重连提示 | 单独开启尝试进度、连接成功及次数耗尽的短暂文字提示；不改变重连开关 |
| 自动省电设置 | 系统省电模式页增加分类，自动开关默认关闭，阈值 20%～80%、默认 20%；未接电且严格低于阈值时开启普通省电，本轮手动关闭后保持关闭 |
| 超级小爱自定义模型与人格 | 小爱设置管理 API Key 和模型。侧栏“人格”打开独立页面，可新建、编辑、使用和删除多个人格。每次使用一个人格，旧设定自动迁移 |
| 控制中心截屏菜单 | 长按截屏磁贴选择模式。区域截屏打开系统选区，长截屏使用系统滚动捕获 |
| 模块界面 | Miuix 风格：首页状态／设备、设置包名列表、关于说明；底部导航水平推动，分类页沿用系统 Activity 动画；支持系统深浅色 |

全局开关默认关闭，保存后重启生效；收回手势位于设置 → 手机管家，× 位于设置 → 系统界面。广告开关分别位于设置 → 日历、设置 → 天气，需在 LSPosed 勾选日历 `com.android.calendar` 和天气 `com.miui.weather2`。已有功能需要 SystemUI 和 Settings；侧边栏呼出功能另需勾选系统桌面 `com.miui.home` 与手机管家 `com.miui.securitycenter`，并先开启系统侧边栏、允许当前应用显示。本版不注入 `system_server`、Updater、蓝牙服务或控制中心插件。宿主启动时验证完整构建、APK 版本和 SHA-256；不同文件或未核验 split 会跳过功能，不按同名版本盲目放行。

截屏菜单需要同时勾选系统界面 `com.android.systemui` 和截屏 `com.miui.screenshot` 作用域。在 HYPERNOVA 的“设置 → 系统界面”或“设置 → 截屏”开启“控制中心截屏菜单”后重启。区域截屏在系统选区中点保存，取消会丢弃选区。长截屏在编辑器中点右上角对勾保存，当前区域不支持长截屏时会提示。

蓝牙自动重连需要同时勾选设置和系统界面作用域，在模块的任一对应分类开启全局开关并重启。再到系统“设置 → 蓝牙 → 已配对设备详情 → HYPERNOVA”逐台开启自动连接并选择次数，单设备选项默认关闭、1 次，保存后立即生效。提示开关位于模块的系统界面分类，默认关闭。设备配置使用专用系统配置键，不要求启动模块程序；停用模块并重启后不会继续发送模块重连请求。

自动省电需要勾选手机管家作用域，在模块“设置 → 手机管家”开启“自动省电设置”并重启。随后进入系统“省电模式”页面底部的 HYPERNOVA 分类，开启“自动打开省电模式”并调整阈值；页面选项保存后立即生效。默认关闭、20%，范围 20%～80%、步进 1%；等于阈值时不触发。手动关闭后本轮不再强制开启，插拔电源或电量恢复到阈值后再次下降时重新触发。接电及关闭自动选项不自动退出已有省电模式。

超级小爱功能需要勾选 `com.miui.voiceassist` 作用域，在模块“设置 → 超级小爱”开启“自定义模型与人格”并重启。小爱设置中的“自定义 API Key”管理模型，侧栏中“智能体专区”下方的“人格”管理头像与风格。详见 [0.2.16 开发版说明](docs/releases/0.2.16-dev.md)。

在“人格”列表点“使用”切换当前人格，删除当前人格后回到小爱默认人格。双击底部手势线等入口唤起小爱后，浮窗键盘发出的文字查询使用当前设定，回复卡片和编辑框会去除模块追加的提示词。小爱先完成转写再作为文字提交的查询、以及直接发送的原生大模型文字请求也会附加人格偏好。仅参考自定义人格适用于应用内的自定义模型。直接流式语音和连续通话暂未适配。

在编辑页点头像并选图，拖动和缩放即可调整裁剪范围。点“完成”把裁剪结果带回编辑页，再点“保存”应用。

自动省电功能见 [0.2.12 开发版说明](docs/releases/0.2.12-dev.md)，阈值实时显示见 [0.2.14 开发版说明](docs/releases/0.2.14-dev.md)，构建步骤见 [BUILDING.md](BUILDING.md)。

## 完整首期目标

1. 在控制中心移动数据磁贴显示今日移动流量，保留原有开关、长按和 SIM 卡行为。
2. 隐藏目标固件中系统 OTA 的入口、搜索结果、红点、通知和弹窗；阻断客户端发起的新检查、下载与安装请求。
3. 隐藏恢复出厂设置入口。按用户最新要求，当前不开发重置执行拦截。
4. 长按单条通知进行锁定或独立置顶，各限一个目标；取消后恢复正常行为。
5. 移植返回手势停留呼出侧边栏：左右两侧、可调阈值、震动和图标反馈、松手打开、回划取消。
6. 通知中心底部一键清理，保留锁定通知；模块页面增加切换动画；隐藏并禁用原生侧边栏触发区域。
7. 屏蔽日历、天气的专用广告加载及广告卡片，保留正常日程、节日、天气和空气质量功能。
8. 侧边栏向外滑动收回，以及小窗右上角直接关闭按钮；关闭行为由用户确认沿用系统原生方式。
9. 移植蓝牙设备自动重连：逐设备开关及次数、有限重试、手动断开暂停、后台执行与可选提示。
10. 在系统省电模式页设置未接电低于自定电量时自动开启普通省电，阈值 20%～80%。

“系统更新”在本期指 ROM/系统 OTA；应用商店更新、普通系统应用更新、Google Play 系统更新不自动纳入。流量默认沿用源模块口径：设备当前时区当天零点至今，全部 SIM 的移动数据接收量与发送量之和，不含 Wi-Fi。

网络屏蔽不包含全设备防火墙；恢复出厂功能目前仅隐藏入口，不阻止实际清除，也不限制 Recovery、Fastboot 或刷机工具。已经交给底层引擎执行的更新不承诺撤销。

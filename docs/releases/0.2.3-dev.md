# HYPERNOVA 0.2.3-dev

日期：2026-11-16。versionCode `6`，沿用调试证书，可覆盖安装 0.2.2-dev 并保留配置。本次只调整模块界面，侧边栏、通知、流量和入口隐藏 Hook 沿用旧版。

## 本次修改

- 首页改为模块状态和设备信息。按用户提供的 SukiSU 截图采用大标题、状态大卡、功能数量与框架 API 双列卡、设备信息列表。
- 状态卡显示真实的模块自身激活状态与版本；未激活、配置不可用或构建不匹配时分别提示，不把自身激活当作所有宿主已经生效。
- 设置页显示原首页的应用名称／包名列表，进入各应用管理功能。跨包选项仍共用现有配置键。
- 关于页放置使用方式、作用域、功能说明、来源与许可证。
- 修正底部文字占满列后左对齐、与居中图标偏位的问题；图标文字统一居中，保留系统手势区间距。
- 包名分类子页高亮“设置”；标题栏返回和系统返回均回到设置列表。

首页显示的设备、框架 API 和已开启选项数量来自实际信息，不使用参考截图中的 root／内核／Zygisk 版本。界面继续使用原生 View 实现 Miuix 风格，状态卡有系统深浅色资源。

## 升级与验证

覆盖安装后重新打开模块，即可查看界面调整。确认三页内容与底部入口对应、图标文字居中、分类页返回设置列表；再检查深浅色、大字体和旋转。此版本没有修改 Hook 配置或作用域，已有功能继续按原来的重启规则生效。

本地验证包括现有 36 项单元测试、Lint、离线构建、APK 入口／桥接／依赖检查、资源、版本、签名及 ZIP 对齐。新的界面布局尚未在开发端连接手机验证，不用构建结果代替真机截图验收；侧边栏实机回归状态仍见 [0.2.2-dev 说明](0.2.2-dev.md)。

# HYPERNOVA 0.2.12-dev

日期：2026-11-17。versionCode `15`，沿用已有调试证书，支持覆盖安装保留配置。

## 自动省电

系统“省电模式”页面底部增加 HYPERNOVA 分类：自动开关默认关闭；开启后显示 20%～80%、步进 1%、默认 20% 的阈值滑动条，关闭后隐藏并保留阈值。

未接通电源且电量严格低于阈值时，复用原生流程开启普通省电模式。页面配置保存立即生效，退出页面后仍由手机管家后台进程处理。手动关闭后本轮不强制开启，重新插拔电源或恢复到阈值再下降时重新触发。接电／关闭自动选项不替你关闭当前省电；已有超级省电与原生定时、充电退出策略继续由系统管理。

## 使用

1. 覆盖安装，在 LSPosed 保持勾选手机管家 `com.miui.securitycenter`。
2. 模块“设置 → 手机管家”开启“自动省电设置”，重启手机。
3. 进入截图对应的系统“省电模式”页面，在底部 HYPERNOVA 分类开启“自动打开省电模式”并调整触发电量。

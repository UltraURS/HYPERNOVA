# HYPERNOVA 0.1.0-dev

日期：2026-11-16。包名 `io.github.hypernova`，versionCode `1`，最低 Android 15。**开发预览版：未连接设备、未进行真机注入或视觉验收。**

## 已实现

1. 模块与设置双页。参考 Connect Colours 的圆角卡片、环境信息与分组开关，使用独立矢量图标和浅色配色，处理 Android 15 系统栏边距。
2. 三个独立开关，默认关闭；共享配置不可用或构建不匹配时不可修改。不以模块自身激活推断宿主已受保护。
3. 今日移动流量：统计设备当前时区自然日的全部移动网络收发总量，在原移动数据磁贴标题显示。查询在后台执行，多个磁贴实例共享查询和缓存；面板监听结束停止定时，销毁实例不接受结果，后台 stale 监听不启动轮询。
4. 精确隐藏 `miui_updater` 和 `factory_reset_key` 条目。只设置原 Preference 的可见性，保留对象和控制器，不删除版本信息或其他重置设置。
5. 宿主版本、完整 fingerprint、APK SHA-256 和关键成员校验。已给样本之外的 APK 或 split 不自动兼容；校验在后台执行，避免阻塞宿主主线程。

## 安装与验证

1. 安装开发版 APK，在 LSPosed 启用 HYPERNOVA，勾选 **系统界面 `com.android.systemui`** 和 **设置 `com.android.settings`**。
2. 重新打开 HYPERNOVA，确认“模块自身已激活”和配置可用，再逐项打开需要的功能。
3. 重启手机，检查 LSPosed 中 `[HYPERNOVA]` 日志。`LOAD` 是包回调；`INSTALLED` 是安装完成；`OBSERVED` 才表示对应业务调用经过。它们都不独立等于验收通过。
4. 展开/收起控制中心，观察流量标题、原点击和长按行为；进入“我的设备”核对两个入口。保留 HyperCeiler 当前配置进行首次联调。
5. 要恢复原行为，关闭对应开关或停用模块并重启。

本版不要求勾选系统框架、Updater 或控制中心插件。所有修改只存在于进程运行时，不更改系统 APK、hosts 或其他模块配置。

首次打开宿主时，后台样本校验可能晚于页面创建；需等待日志出现 `INSTALLED` 后离开并重新进入相关页面/控制中心再验证。`CONFIG_UNAVAILABLE` 时先检查模块是否启用、打开模块保存配置，然后重启；`UNSUPPORTED` 时保留日志和实际包路径，不绕过校验。

## 未完成与限制

- **入口隐藏不是重置阻断**：“更多设置”推荐入口、搜索、直接跳转、广播、设备策略及厂商执行链均未完整拦截。不得通过确认真实擦除来测试本版。
- **未实现 OTA 服务器/检查/下载/安装阻断**：当前 ROM 无更新器；隐藏设置条目不代表客户端或服务器被封锁，也不会取消已提交的更新任务。
- `miui_updater` 条目在该 ROM 中可能原本不可见；本版不会制造一个入口来展示隐藏效果。
- LSPosed 截图所示 API 102 的传统接口和共享偏好桥接仍需真机确认；未要求关闭现有 API 调用保护。
- 未确认 split 完整性、实际权限、HyperCeiler 版本/作用域。严格样本校验失败时会跳过功能；不以同版本号兜底。
- 统计更新速度受系统历史数据影响，不等同运营商账单；暂未真机验证双卡、无卡、字体放大、无障碍或横屏。

## 本地验证

- 11 项纯逻辑测试通过：自然日/夏令时/跨年、单位、大流量、负值与溢出、缓存过期/跨日/时区/回拨、两个隐藏开关独立性及无关设置保留。
- DEX：原始样本哈希及 14 个相关成员匹配。
- Android 构建通过；Lint 无问题。APK v2 签名、ZIP 对齐、Xposed 入口与 DEX 打包检查通过；未打包 Xposed API、JUnit 或原模块类。
- 未执行手机安装、真实更新/擦除、端到端 Hook 测试或界面截图验证。

完整后续目标仍按 [实施计划](../implementation-plan.md) 推进。当前 APK 只承载上述基础功能，不代表 P1–P6 真机验收全部完成。

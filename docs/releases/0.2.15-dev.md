# HYPERNOVA 0.2.15-dev

2026-11-18。versionCode 为 `18`，沿用同一签名证书。

## 超级小爱自定义模型

在 LSPosed 勾选超级小爱 `com.miui.voiceassist`，在 HYPERNOVA 的“设置 → 超级小爱”开启“自定义模型与智能体”，然后重启。进入超级小爱设置，在列表底部点“自定义 API Key”。

为每个模型填写名称、HTTPS API 地址、模型 ID 和 Key。可以填写基础地址（例如 `https://example.com/v1`）或完整的 `/chat/completions` 地址。保存后点选模型，可随时改选“小爱默认模型”。模型需要支持返回文本的 JSON 响应，接口字段见 [Chat Completions 文档](https://developers.openai.com/api/reference/resources/chat)。

选中自定义模型后，超级小爱主界面用键盘发送纯文本会打开对话窗口，带入刚输入的内容。窗口显示模型和目标服务器，再点“发送”才提交。小爱默认模型、语音和带附件的请求沿用宿主流程。

## 本地智能体

在智能体专区底部点“自定义智能体”，填写名称和提示词后即可保存。点已保存的智能体可开始对话，也可编辑或删除。已选自定义模型时直接使用该模型。选中小爱默认模型时，可以为本次智能体对话临时选择一个已保存的自定义模型。

模型配置、Key 和提示词使用 Android Keystore 中的密钥加密，保存在超级小爱进程的私有目录。智能体定义在本机创建和管理。发送对话时，选定的 API 会收到本次对话和智能体提示词以生成回答。对话历史只存在于当前窗口。

## 适配与验证

对应提供的超级小爱 7.9.11.1910（versionCode `507009011`）和 Redmi Note 12T Pro / HyperOS 3.0.3.0.VLHCNXM。已核对 49 个新增方法和字段所在的 DEX。设置从 `MiuiVoiceSettingActivity$a` 插入原生入口，专区仅在 `llmskilllist.bundle` 路由预留本地按钮，纯文本从 `ConversationFragment$d` 持有的 `ff0.e0.onSendClick` 接入。

自定义请求使用单独创建的宿主 OkHttp 客户端。样本中该客户端的空白构造器使用空 Cookie 存储和空认证器，模块为每次请求设置当前配置的 Bearer Key，并关闭重定向。测试覆盖默认与多模型选择、地址校验、加密往返、篡改拒绝、提示词角色和文本响应解析。

独立的宿主替身验证了切换模型后使用对应地址和 Key、系统提示词提交、拒绝重定向、释放响应和发送前取消。安装包构建、签名、96 项单元测试和 Lint 均通过。真机验收需检查两个入口的位置、普通键盘发送和默认模型切换，以及兼容服务商的实际回复。

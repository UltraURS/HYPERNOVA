# HYPERNOVA 0.2.5-dev

日期：2026-11-16。versionCode `8`，沿用已有调试证书，可覆盖安装并保留配置。

## 本次修改

- 修复侧边栏呼出后无法交互：进入原生展开准备 `Q()` 前先恢复收起遮罩，并在该调用期间停止附加不可触摸位；原生清除 `FLAG_NOT_TOUCHABLE` 的结果得到保留。完成或异常后按真实展开状态刷新，关闭后继续隐藏原触发条。成功回执增加窗口可触摸／透明度检查。
- 新增“设置 → 日历 → 屏蔽日历广告”：走原生推广关闭分支，拦截专用广告加载、取消可识别的在途广告 Call，并抑制缓存广告卡片，保留日程和节日等普通内容。
- 新增“设置 → 天气 → 屏蔽天气广告”：拦截预报详情、首屏专用广告请求，隐藏整个详情广告容器，过滤首页共用内容及缓存中的广告节点并阻止专用广告事件报告，保留预报、空气质量、生活指数和普通内容。

侧栏修复不新增触摸窗口，不修改桌面普通返回手势。广告功能不改 hosts／DNS／防火墙。共用内容请求保留，因此其响应可能仍包含广告 JSON；模块在展示前过滤，不声称共用接口零广告数据或校验前零请求。详细边界见 [广告适配记录](../adaptation/calendar-weather-ads.md)。

## 使用

1. 覆盖安装并打开模块，原有侧栏配置保留；侧栏本身保持系统启用。
2. 需要广告屏蔽时，分别在日历、天气分类开启选项，并在 LSPosed 新增勾选日历 `com.android.calendar`、天气 `com.miui.weather2`。九个选项均为默认关闭，新广告选项不会自动启用。
3. 重启手机加载新 Hook。优先确认左右侧栏的点击、滚动、打开应用、点击外部关闭；关闭后原触发条仍应隐藏，两侧普通返回正常。
4. 再检查日历月视图及天气首页／15 天预报，包含原有广告缓存、刷新、切换日期／城市、离线和正常内容操作。

只适配目标固件及本次日历 17.0.6.26、天气 17.0.3.15 的文件哈希；不同 APK 或 split 跳过该功能。总作用域为系统界面、设置、系统桌面、手机管家、日历、天气六项，不新增 Updater 或系统框架注入。

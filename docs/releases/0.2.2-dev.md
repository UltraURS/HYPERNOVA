# HYPERNOVA 0.2.2-dev

日期：2026-11-16。versionCode `5`，沿用调试证书，可覆盖安装 0.2.1-dev 并保留配置。用户反馈 0.2.1-dev 侧边栏无法呼出，本次修改计时起点、修正相反侧根窗口隐藏并调整界面；**本版尚待真机回归，不能据本地测试宣称已经解决所有呼出问题。**

## 本次修改

- 侧边栏改为从系统返回就绪震动回调开始计时，默认 0.30 秒，范围 0.10～0.50 秒、步进 0.01 秒。不再要求内滑至动画最大距离。
- 到期将箭头切换为侧边栏图标，不额外发出一次模块震动；松手打开对应侧面板。计时中或就绪后回划会取消，不额外执行返回；正常短划仍交给系统。
- 未命中原生回调不启动计时，重复回调不延长时限；保留 UP 实际时间、多指、旋转、锁屏和视图分离检查。
- 普通模式下相反侧原生根窗口可能为 GONE，打开时临时恢复可见，原生关闭或请求失败后恢复原状态；仍共用系统原生应用列表及显示限制。
- 界面改为 Miuix 风格原生 View：灰底圆角列表、应用图标／名称／包名、蓝色开关、首页／设置／关于导航，随系统深浅色切换。
- 按包名分类功能。侧边栏开关与阈值同时出现在系统桌面和手机管家分类，始终使用同一份原配置，不新增两套开关或重置已有值。没有引入 Compose 或 Miuix SDK。

其他已有功能保持范围：恢复出厂仅隐藏；通知仍按单条 key 各锁定／置顶一条；缺少 OTA 客户端时显示不适用，不启用设备级网络封锁。

## 升级与验证

1. 覆盖安装 APK，确认 LSPosed 中已启用模块。侧边栏需要系统桌面 `com.miui.home` 与手机管家 `com.miui.securitycenter` 两个作用域；保留已有基础作用域。
2. 在系统设置中先开启侧边栏并允许当前应用显示。进入模块首页的系统桌面或手机管家分类，打开侧边栏选项、确认阈值后重启。
3. 从屏幕侧边内滑至系统返回就绪震动，保持手势，默认再过 0.30 秒图标变化后松手。分别验证左右两侧、回划取消和普通短划。
4. 在两个分类间切换，检查开关和阈值相同；检查深浅色、大字体、页面返回、旋转及配置保留。

若仍不能呼出，LSPosed 日志可按 `FEEDBACK → READY → REQUEST → ACCEPTED` 定位阶段。手机管家拒绝时另有 `UNAVAILABLE reason=...`；无应答 3 秒显示提示，不无限重试。ACCEPTED 只表示原生流程接受且窗口附着可见，不代表最终动画渲染成功。

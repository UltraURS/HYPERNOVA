# HYPERNOVA 0.2.7-dev

日期：2026-11-17。versionCode `10`，沿用已有调试证书，可覆盖安装并保留配置。

## 本次修改

- 小窗右上角 × 的线长和笔画粗细同比缩小 50%，保持居中，原 36 dp 点击区域、按钮位置及原生关闭行为不变。
- 通知中心清理按钮下移，参考用户提供的后台清理 × 的高度。底边距从安全距离加 `max(64 dp, 容器高度 × 7.5%)` 改为安全距离加 `max(24 dp, 容器高度 × 2.5%)`，继续保持水平居中并适应布局变化。

通知清理仍保留锁定及系统不可清除的通知。没有增加开关、作用域或宿主声明；已有功能及配置沿用上一版。

## 使用与验证

覆盖安装后重启手机。已有“小窗右上角关闭按钮”和“通知中心一键清理”开关开启时即可使用调整后的样式。

本地通过：59 项单元测试（0 失败／错误／跳过）、Lint（0 问题）、离线构建、APK 入口／桥接／依赖检查、版本核对、v2 签名及 4 字节 ZIP 对齐。本次只改绘制和位置参数，没有新增测试或重新执行未变化的宿主声明核验。

开发端未连接目标手机。通知按钮依据截图下移，实际与后台清理按钮的对齐程度、小窗 × 的观感和点击需在设备确认。

# HYPERNOVA 0.2.1-dev

日期：2026-11-16。versionCode `4`，与 0.2.0-dev 使用相同调试证书，可覆盖安装。**本版已接入双侧返回手势呼出原生侧边栏，尚未连接手机或完成真机验收。**

## 本次修改

- 设置页增加“屏幕边缘返回手势呼出侧边栏”，默认关闭。
- 触发阈值 0.10～0.50 秒，默认 0.30 秒，滑块步进 0.01 秒；拖动结束保存，键盘／无障碍调整也保存。
- 从屏幕左侧或右侧向内滑至返回动画最大位置后才开始计时，达到阈值震动并切换为侧边栏图标；松手打开对应侧面板。仅出现箭头时停留不触发，计时期间离开最大位置会清零。
- 就绪后向边缘回划会取消整次操作，再向内也不重新触发；不会同时执行返回。短划返回仍交给系统。
- 使用原生左右面板与同一应用列表，右侧不另建应用配置或常驻手柄。保留系统当前游戏／视频／普通侧边栏模式。
- 增加多指、系统取消、不可触摸、配置变化、旋转、锁屏和视图分离检查；按 UP 事件实际时间防止界面卡顿把短划误判为呼出。
- 图标沿用原箭头颜色、大小和原生透明度动画，绘制后恢复原 Bitmap；跨进程应答使用系统 ResultReceiver，不要求宿主加载模块回调子类。

原有通知、流量和设置入口 Hook 不变。恢复出厂仍仅隐藏入口；OTA 仍限客户端，缺少更新器时显示不适用。

## 升级与启用

1. 覆盖安装新 APK，确认 LSPosed 已启用 HYPERNOVA。
2. 保留原有“系统界面”“设置”作用域；侧边栏功能另勾选“系统桌面”`com.miui.home` 与“手机管家”`com.miui.securitycenter`。
3. 使用全面屏手势，在系统设置中先开启侧边栏，并允许当前应用显示。
4. 在模块设置打开新开关，按需调整阈值，重启手机。
5. 分别从左右侧向内将返回动画拉至最大，停住至图标变化后松手；再验证未拉满长按不触发、回划取消和短划正常返回。

开关、阈值仍按保存后重启生效。模块不会自动打开系统侧边栏、改变原生手柄位置或放宽系统显示限制。原生排除区域和转交给其他原生手势的事件保持原行为。

## 适配与诊断

已核验用户补充的系统桌面 RELEASE-6.01.03.1943-01051706 / 601031943 和手机管家 12.1.3-251205.0.1 / 40001213。新增两端都校验设备构建、两份 APK 的版本和 SHA-256，不放行未知 split。

桌面 Hook 原生 `GesturesBackTouchProcessor` 和 `GestureBackArrowView`；手机管家只进入 `com.miui.securitycenter:ui`，通过原本受签名权限保护的服务处理专用请求并选择左右包装器。没有加入系统框架中继、修改 provider 或绕过组件权限。

日志包括 `sidebar-gesture INSTALLED holdMs=...`、`READY side=...`、`REVERSED`、`sidebar-panel INSTALLED`、`ACCEPTED side=...` 和明确的安装／请求错误。ACCEPTED 表示原生面板流程已接受请求，不代表动画已完成显示。未响应时 3 秒后提示检查作用域；服务未激活或当前不允许显示时提示系统侧边栏不可用，不无限重试。

详细证据和真机验收项见 [侧边栏适配记录](../adaptation/sidebar-gesture.md)。现有 HyperCeiler 备份中，禁用全面屏返回手势和隐藏侧边栏开关均为 false；这只能说明备份配置，不代替实际共存验证。

## 本地验证与限制

- 33 项单元测试通过，其中侧边栏新增 13 项，覆盖全部 41 个滑块档位、默认／边界、仅最大位置计时、单次提示、回划、短划、中断、方向与迟到定时器。
- Lint 无问题，离线构建通过。
- 86 个原始固件成员与哈希匹配；成品 Xposed 入口、通知桥接 DEX、侧边栏类和依赖排除检查通过。
- APK v2 签名、ZIP 对齐与包名／版本检查通过；调试证书与 0.2.0-dev 一致。

以上均为开发端验证。手机上的双侧触发手感、实际震动和图标、面板布局与应用启动、旋转／中断、权限授予及 HyperCeiler 共存仍待验证。

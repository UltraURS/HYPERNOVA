# HYPERNOVA 0.2.8-dev

日期：2026-11-17。versionCode `11`，沿用已有调试证书，可覆盖安装并保留配置。

## 本次修复

修正通过模块手势打开侧边栏后，点击其中的应用可能同时点到底层 QQ 等界面的问题。

目标固件创建面板时可能设置 MIUI 点击向下传递标志，原生触摸结束后会调用 `A4.n.X0(wrapper)` 清除；模块呼出流程此前没有执行这一步。本版在面板创建完成后、展开动画开始前补调用原生清理方法，成功回执前再调用一次，覆盖已经打开的面板重复请求。左右侧共用处理。

保留其他窗口标志和原生点击、滚动、长按及关闭逻辑。不增加全屏触摸层、不新增开关或作用域；收起时隐藏触发条及普通返回手势仍使用原路径。上一版小窗 × 缩小和通知清理按钮下移继续保留。

## 使用

覆盖安装后重启手机，保留原有设置即可。检查在侧栏点击 Authenticator 等应用时，底层同位置的 QQ 会话不被同时打开；左右两侧都需确认。

## 验证与限制

- JVM 回归编译实际 `SidebarPanelHook`、`SidebarTriggerHook`、`SidebarSwipeHook` 及收回手势类。旧代码在“展开后必须清除 MIUI 点击向下传递标志”断言失败，修正后通过。
- 回归覆盖左右侧各三次呼出、既有面板重复请求、隐藏触发条开关两种状态、其他 MIUI 标志保留，以及既有布局更新、异常重试、收回动画和即时关闭路径。
- 59 项单元测试通过，0 失败／错误／跳过；Lint 0 问题，离线构建通过。
- 188 项固定固件声明及 162 条 DEX 定位证据通过；APK 入口／桥接／依赖、版本、v2 签名及 4 字节 ZIP 对齐检查通过。

开发端未连接目标手机。宿主模型验证了标志清理与调用时序，不模拟真实系统输入分发；本次用户报告场景以及列表滚动、长按、向外收回和关闭后的普通返回仍需按 T38 实机确认。

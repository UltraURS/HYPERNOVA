# HYPERNOVA 0.2.9-dev

日期：2026-11-17。versionCode `12`，沿用已有调试证书，可覆盖安装并保留配置。

## 本次调整

- 小窗 × 的中心与原生 ··· 的布局中心水平对齐，使用宿主的 `mCaptionY + getDotY()` 定位。
- × 距离小窗顶部和物理右边缘的留白相等，随任务重排及既有缩放回调重新计算。保留半像素位置，避免奇数像素尺寸产生对齐误差。
- 将原 36 dp 点击窗口收缩到图标的外接正方形，不再保留额外热区。保留 0.2.7 缩小后的图标视觉大小，约 7.48 dp，按缩放反算任务像素并同步更新 ViewHost 尺寸和 Surface 裁剪。

关闭仍沿用原生行为，将当前小窗任务转到后台。作用域、开关及已有配置不变；0.2.8 的侧栏点击隔离修复继续保留。

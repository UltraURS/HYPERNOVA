# HYPERNOVA 0.2.6-dev

日期：2026-11-17。versionCode `9`，沿用已有调试证书，可覆盖安装并保留配置。

## 本次修改

- 侧边栏向外滑动收回：在已展开的原生应用列表上，左侧向左、右侧向右滑动后松手，调用原生 `h1 → i1` 收回动画。区分纵向滚动、长按、多指、内划和取消，接管后取消子项点击。
- 收回动画与隐藏触发条协调：原生 `U(false)` 出现在动画开始时，本版在动画完成 `K0` 后再隐藏窗口并恢复辅助窗口可见性；即时关闭或异常也清理收回状态，避免动画被提前截断。
- 小窗右上角 ×：在普通小窗内创建局部任务子窗口，随任务移动、缩放和装饰生命周期更新；点击原生小窗关闭。按用户确认，该操作退出当前小窗并把任务转到后台。

× 使用原 `MiuiCaptionButtonClickListener.handleCloseClicked`，保留锁定任务模式限制和当前任务存在／小窗状态检查。按钮显示不扩大小窗原三点窗口的触摸范围，不新增全屏悬浮窗或悬浮窗权限。迷你化、全屏、任务隐藏／退出和装饰释放时处理可见性与回收；点击后防止重复提交。

## 使用

1. 覆盖安装并打开模块。
2. 在“设置 → 手机管家”开启“侧边栏向外滑动收回”。它可用于原生或模块手势打开的侧栏；系统侧边栏本身保持启用。
3. 在“设置 → 系统界面”开启“小窗右上角关闭按钮”。
4. 保存后重启手机，再检查左右收回方向、动画、列表点击／滚动及小窗按钮。

两个新开关默认关闭；原有配置和阈值保留。作用域仍为系统界面、设置、系统桌面、手机管家、日历、天气六项，无新增包名。继续只适配已核验的目标固件和 APK 文件。

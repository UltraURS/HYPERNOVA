# HYPERNOVA 0.2.13-dev

日期：2026-11-17。versionCode `16`，沿用已有调试证书，支持覆盖安装保留配置。

## 自动省电页面修复

- 阈值标题直接显示“触发电量：N%”，兼容手机管家不显示滑动条数值／摘要的布局。松手保存后更新，重新进入页面显示保存值，保存失败保留旧值。
- HYPERNOVA 分类提前到原生选项创建完成后加入，在首次列表绑定前准备好控件。进入此省电页时结束并停用其条目动画，避免上方超级省电选项单独上移；不全局修改 RecyclerView 或 Activity 切换动画。

阈值仍为 20%～80%、步进 1%、默认 20%；自动省电触发、充电保护与本轮手动关闭规则沿用 0.2.12。

## 使用

覆盖安装后重启手机，保持手机管家作用域及模块内“自动省电设置”开启。进入系统“省电模式”页面，开启底部“自动打开省电模式”，检查标题百分比及原生条目位置。页面内开关和阈值保存即时生效。

## 验证与边界

扩展实际页面 Hook 的 JVM 模型，旧实现先复现标题无百分比、绑定后插入分类与原生行独立动画；修复后通过。覆盖 20%／80%／恢复的 50%、保存失败、首帧控件、反复进入、当前列表动画结束及其他列表保持原有动画；后台回归一并通过。

全工程 91 项单元测试通过，0 失败／错误／跳过；Lint 0 问题。离线构建、APK 入口／桥接／依赖排除、CRC、版本、v2 签名及 4 字节 ZIP 对齐检查通过。248 项宿主声明核验通过，新增 3 条定位在手机管家实际 DEX 中确认，总定位记录 222 条。

开发端未连接手机，模型不渲染真实 Miuix 控件；实际布局、滑动触摸与动画按 T42 真机验收，后台电源策略仍按 T41 验收。

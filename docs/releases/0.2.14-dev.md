## 使用

覆盖安装后重启手机，保持手机管家作用域和模块内“自动省电设置”开启。进入系统“省电模式”页面，在 HYPERNOVA 分类开启自动选项，拖动阈值时检查百分比即时变化；松手保存后退出再进入，检查保存值。

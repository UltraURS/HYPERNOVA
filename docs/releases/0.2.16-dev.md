# HYPERNOVA 0.2.16-dev

2026-11-18。versionCode 为 `19`，沿用已有签名。

超级小爱侧栏“智能体专区”下方新增“人格”，取代 HYPERNOVA 上一版的“自定义智能体”入口。保存后会在后续对话应用，可从系统照片选择器导入头像，并说明小爱应有的身份、性格和表达风格。头像与人格加密保存在本机。API 模型和旧版本的配置文件可直接升级，旧智能体记录不会被重新启用。

- 关闭“参考默认人格”后，自定义模型的每轮请求只包含填写的人格设定作为系统消息。开启时，用户设定优先，冲突之外的部分可参考模块提供的默认小爱风格。
- 在小爱默认模型下会使用“参考默认人格”。主界面联网键盘文字请求附加人格偏好，原问题仍用于原生聊天界面。是否遵循偏好由小爱服务端决定。语音输入、附件和系统动作回复仍走各自的原生入口。
- 原生模型下“参考默认人格”固定开启，切回自定义模型会恢复上次选择。头像用于人格编辑和自定义对话。发往外部模型的是对话和人格文字设定。

侧栏条目复用原生适配器的 `SKILL` 行。模型选择、API Key 编辑、对话及人格表单使用超级小爱自带的 Miuix 控件。头像按比例缩小、居中裁成方形，保存像素数据。

适配包仍为超级小爱 7.9.11.1910。原生文字在 `ff0.e0.onSendClick` 确认主界面键盘来源，标记随宿主构造的 Intent 传到语音配置和 NLP 请求对象。在 `m10.m0.I0/J0` 创建 NLP 载荷时才附加提示，保留传给原生界面的问题。

99 项单元测试和 Lint 通过。JVM 模型验证了两个原生 NLP 分支、异步请求传递、原问题保留、伪造标记和无关请求隔离。核对 338 项宿主声明，其中超级小爱 87 项。实际样式、照片选择器及小爱服务端遵循程度待真机验证。

已启用上一版的设备可覆盖安装并重启。首次使用请在 LSPosed 勾选 `com.miui.voiceassist`，再到 HYPERNOVA“设置 → 超级小爱”开启“自定义模型与人格”。

安装包为 `dist/HYPERNOVA-0.2.16-dev.apk`，347111 字节。同目录提供 SHA-256 校验文件。

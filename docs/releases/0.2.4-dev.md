# HYPERNOVA 0.2.4-dev

日期：2026-11-16。versionCode `7`，沿用已有调试证书，可覆盖安装 0.2.3-dev 并保留配置。

## 本次修改

- 右侧侧边栏：临时恢复原生面板及触摸覆盖窗口，等待手柄完成布局后再启动原生展开动画。动画完成且内容位于正确一侧后才回执成功，2 秒内未显示则回执不可用，避免旧版提前成功却没有面板的情况。用户只确认过左侧能打开，右侧修正尚待设备验证。
- 侧边栏就绪：系统原生返回震动后继续按设定阈值计时，到期调用同一个原生触感接口一次，并将箭头换成新的方形侧边栏图标。保留左右镜像、原色、透明度和位图密度，结束绘制后恢复原箭头及尺寸字段。
- 隐藏系统侧边栏触发条：手机管家分类增加独立开关。收起状态将原生窗口完全透明并设为不可触摸，保留布局和服务；展开时恢复窗口交互，关闭后重新隐藏。不新增触摸窗口，不拦截系统桌面的普通返回事件，不修改系统侧边栏启用设置。
- 通知中心一键清理：系统界面分类增加独立开关，复用原生清理按钮并放在底部居中、手势条上方。普通及仅置顶通知可清理，锁定通知和系统不可清除通知保留；补上批量与列表清理的锁定保护。
- 页面动画：底部导航按顺序水平推动，支持反向切换、快速切换及系统关闭动画；应用分类改为独立 Activity 页面，进入／返回沿用系统默认动画，返回原设置列表并保留位置。

锁定子通知时也保留其分组摘要，避免系统连带删除，其他未锁定子通知仍可清理。锁定分组摘要时保留其子通知，避免摘要因子项全部消失而被自动移除。应用自行撤回通知仍按原生行为处理。

## 使用与验证

覆盖安装并打开模块：

1. 在“设置 → 系统界面”开启“通知中心一键清理”。
2. 在“设置 → 手机管家”开启“隐藏系统侧边栏触发条”；需要通过返回手势打开时，同时开启原有的返回手势呼出功能。系统侧边栏本身保持启用。
3. 作用域仍为系统界面、设置、系统桌面、手机管家四项，本次不增加作用域。开关保存后重启手机加载新的宿主 Hook；页面动画在升级后打开模块即可查看。

本地验证通过：40 项单元测试（0 失败、0 跳过）、Lint（0 问题）、离线构建、116 个固件目标声明、证据 JSON 的 90 条文件／DEX／成员定位记录、APK 入口／桥接／依赖检查、版本、v2 签名和 4 字节 ZIP 对齐。

开发端尚未做真机回归。仍需检查右侧是否真正展开、就绪震动／图标、清理按钮位置及锁定分组保护、隐藏原线后两侧普通返回和边缘触摸有无死区、关闭后再次隐藏、旋转／模式切换、页面动画及 HyperCeiler 共存。对应 T24–T32，不以静态成员命中或构建通过代替设备验收。

# 模块界面

0.2.3-dev 根据用户的页面对应反馈和 SukiSU 首页截图，调整首页／设置／关于三页；0.2.4-dev 增加页面切换动画。保留 Miuix 风格的中性灰背景、圆角卡片、应用图标／名称／包名列表和蓝色胶囊开关。颜色资源提供系统浅色和深色两套，字体跟随系统缩放。

当前工程继续使用 Android 原生 View，没有引入 Compose 或 Miuix SDK。样式参考用户截图和 [Miuix 官方主题说明](https://compose-miuix-ui.github.io/miuix/guide/theme)，图标使用独立绘制的矢量资源；应用图标通过 PackageManager 读取，缺失包使用系统默认图标。没有从 HyperCeiler APK 提取 UI 组件或素材。

## 三页与导航

| 底部入口 | 内容 |
| --- | --- |
| 首页 | 大标题、模块自身激活状态卡、模块版本、已开启选项数量、框架 API、设备及构建信息 |
| 设置 | 应用名称与包名列表，进入对应应用配置功能 |
| 关于 | 使用方式、作用域说明、功能范围、来源与许可证 |

首页参考用户提供的 SukiSU 布局：浅绿状态大卡、右侧装饰图标、下方两列数据卡、标签在左且值右对齐的设备信息列表。数据取自实际模块激活结果、现有偏好和 Android Build，不硬编码截图中的 root、内核或 Zygisk 状态。未激活显示灰色状态，配置不可用或构建不匹配显示提示色；绿色“已激活”只表示模块自身加载，不代表所有宿主功能已经验收。

底部导航的图标与文字均居中，文字使用内容宽度，不再占满整列后默认左对齐。首页采用可滚动大标题，其他页面保留固定标题栏；底部导航单独布局并保留系统手势区安全间距。

首页／设置／关于切换时按底部顺序水平推动，时长 250 ms；导航栏本身保持位置，RTL 时方向相反。重复点击当前页不重放，快速切换先结束上一段动画，不积累旧页面；系统关闭动画时直接切换。动画期间拦截内容区触摸，防止点击正在退出的设置项。

点击包名分类会打开新的 Activity 实例，分类页隐藏底部导航；标题栏和系统返回结束该实例，回到原设置列表并保留滚动位置。进入／退出使用系统默认 Activity 动画，不覆盖 ROM 的系统动画，也不将进出分类页伪装为底部导航切换。分类页及根页面分别保存当前页面，旋转后继续对应内容。

## 包名分类

| 页面 | 包名 | 功能 |
| --- | --- | --- |
| 设置 | `com.android.settings` | 隐藏系统更新条目、隐藏恢复出厂入口 |
| 系统界面 | `com.android.systemui` | 今日移动流量、通知锁定与置顶、通知中心一键清理、小窗右上角关闭按钮 |
| 系统更新 | `com.android.updater` | OTA 客户端适用状态，当前 ROM 缺失时显示不适用 |
| 系统桌面 | `com.miui.home` | 屏幕边缘返回手势呼出侧边栏、触发阈值 |
| 手机管家 | `com.miui.securitycenter` | 同一侧边栏呼出开关和触发阈值、隐藏系统侧边栏触发条、侧边栏向外滑动收回 |
| 日历 | `com.android.calendar` | 屏蔽日历广告 |
| 天气 | `com.miui.weather2` | 屏蔽天气广告 |

设置页的包名列表按上表进入对应分类。`Feature.packages` 声明功能关联的包名，各分类循环同一 Feature 集合生成开关，不按包复制配置。侧边栏两处均读取／写入 `sidebar_back_gesture` 和 `sidebar_hold_millis`；切换分类重新绑定当前偏好，升级沿用已有值。开关仍全部默认关闭，保存后重启生效；共享配置不可用或构建不匹配时禁用写入。

包可见性只补充以上已知应用，未申请 QUERY_ALL_PACKAGES。分类中列出系统更新状态不代表新增 Updater 注入；系统框架和控制中心插件也未加入作用域。

0.2.5-dev 增加日历与天气分类及各自独立开关，默认关闭；关于页补充两项作用域和广告处理范围。升级保留原有七个选项与阈值，首页总功能数从枚举自动更新为九项。启用广告功能需要新增对应应用作用域后重启。

0.2.6-dev 在既有手机管家、系统界面分类增加收回手势和小窗 × 两个独立开关，不增加包名或作用域；首页总数自动更新为十一项。关于页说明收回方向与原生小窗关闭行为。按用户确认，× 退出当前小窗并将任务转到后台。

用户提供的 0.2.2 截图确认底部图标与文字偏位，0.2.3 已修改对应布局。本地编译、Lint 和成品资源检查不等于真机视觉验收。仍需验证三页对应、底部对齐、状态卡、应用图标、系统深浅色、大字体、分类页返回、旋转恢复、保存失败提示、两分类配置同步，以及新增推动画／系统页面动画，见 T29、T31。

0.2.10-dev 新增“蓝牙自动重连”，同时列在设置 `com.android.settings` 与系统界面 `com.android.systemui` 分类，共用同一开关；“蓝牙重连提示”只列在负责显示提示的系统界面分类。两项默认关闭，首页总数由枚举更新为十三项。每台设备的自动连接与 1～5 次下拉选项注入系统蓝牙详情页底部的 HYPERNOVA 分类，不在模块内请求蓝牙权限或另建配对设备列表。单设备选项保存立即生效，全局开关仍需重启。
